A **web-based mini accounting system** designed to **automatically generate financial statements** from journal entries.  
This project simplifies traditional accounting workflows by transforming raw transactions into **ledgers, trial balance, trading account, profit & loss account, and balance sheet** in real time.

---

## 🚀 Features  

- 🔐 **User Authentication** – Secure login and registration system  
- 📘 **Journal Entry Module** – Easy debit & credit entry with narration  
- 📒 **Automated Ledger** – Real-time ledger generation for each account  
- ⚖️ **Trial Balance** – Auto verification of debit and credit totals  
- 📈 **Trading & P&L Account** – Automatic gross and net profit calculation  
- 🏦 **Balance Sheet** – Live assets and liabilities statement  
- 📊 **Graphical Dashboard** – Visual insights for assets, liabilities & profit  
- 🌓 **Light / Dark Mode** – Smooth animated theme switch  
- 📄 **PDF Export** – Download financial statements instantly  
- 💾 **Offline Storage** – Uses IndexedDB for local data persistence  

---

## 🖥️ Tech Stack  

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)  
- **Database**: IndexedDB (Client-side)  
- **Charts & Graphs**: Chart.js  
- **PDF Export**: jsPDF + AutoTable  
- **Icons**: Font Awesome  
- **Fonts**: Google Fonts (Inter & Outfit)
